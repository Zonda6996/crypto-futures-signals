# STRATEGIES: carry-select — единственная живая стратегия

> **Что это:** простыми словами про стратегию, прошедшую ВСЕ гейты программы
> (FINAL-001, вердикт `SELECT`). **Для кого:** человек и любой ИИ. **Статус:**
> in-sample доказана; paper-forward копится с 2026-08-24; резерв 2026-07…08 sealed.

## Суть в одном абзаце

На крипто-фьючерсах трейдеры в лонге платят «аренду» (фандинг) тем, кто в шорте.
Мы каждый день смотрим эту аренду по 10 монетам: **кто платит больше всех — шортим
(перегреты), кто платит меньше всех — покупаем (недооценены)**. Деньги капают с самой
аренды плюс небольшой перевес «толпа в крайности уходит зря». Никакого угадывания
цены и теханализа — только поток платежей и дисциплина выхода.

## Режимы

| | **SAFE** (основной) | **RISK** |
|---|---|---|
| Корзина | шорт топ-3 платильщиков / лонг дно-3 | та же |
| Веса | обратно волатильности (тихим больше) | равные |
| Стоп | 3×ATR от входа (по закрытию дня) | 3×ATR |
| Тейк | **фулл-фикс при +1 стоп** | частичный при +2 стопа, остаток в безубыток |
| Хедж | BTC-шорт под бету книги (~13%) | нет |
| История (5.5 лет) | +763%, Sharpe 1.44, DD −20.9% | +939%, DD −26.7% |
| Статус | **SELECT, все гейты пройдены** | опубликован, ждёт форварда |

## Что происходит каждый день (00:00 UTC)

1. Закрылся дневной бар → считаем средний фандинг за 3 дня по каждой монете.
2. Рейтинг: топ-3 → шортим, дно-3 → лонгуем (кто уже в книге и остался в рейтинге —
   сидит дальше; выпал — закрыли, слот заняли следующим).
3. Проверили стопы/тейки по закрытию; частичка (RISK) — половину в кэш, стоп остатка
   на вход.
4. Подрезали все позиции к целевым весам; пересчитали хедж BTC.
5. Всё записали в журнал.

## Команды

```bash
uv run python -m research.altcoin_carry_forward --run      # прожить день (раз в сутки)
uv run python -m research.altcoin_carry_forward --status   # что в книге, equity, хедж
uv run python -m research.altcoin_carry_forward --symbol ADAUSDT BTCUSDT
# по активу: бэктест-статистика + живая позиция в SAFE/RISK + журнал событий
```

Журнал и **главный отчёт**: `reports/artifacts/altcoin-carry-final-001/forward/report.md`
(обновляется при каждом запуске: книга, хедж, equity, последние события, легенда).
Полный журнал событий: `forward/trades.jsonl`. Бэктест-артефакты: `reports/artifacts/altcoin-carry-final-001/`
(глоссарий всех файлов — `reports/artifacts/README.md`). Серия дневных доходностей
для портфельных расчётов: `select-daily-returns.{csv,json}` там же. Статистика по
каждому активу за 2021–2026: `per-symbol-stats.{json,csv}` там же (или `--symbol`).

## Чего НЕ делать

- Не менять веса/стопы/тейки/сиды без нового freeze — это другой тест.
- Не «подкручивать» по первым неделям форварда: форвард валиден только нетронутым.
- Не читать резерв 2026-07…08 (sealed).
