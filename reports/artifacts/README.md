# Артефакты — что это и почему их много

> Каждая папка = один замороженный протокол (один «эксперимент» программы). Файлы
> внутри — обязательный отчёт прогона, их нельзя править: это доказательная база.

## Папки-протоколы (по хронологии)

| Папка | Что проверяли | Вердикт |
|---|---|---|
| `altcoin-multitf-005-phase3/4` | тренд-семья, 2021–23 (5,832 конфига) | NO_SELECTION |
| `altcoin-multitf-006` | дневной тренд, 2024 | NO_SELECTION |
| `altcoin-multitf-007` | тренд one-shot на всей истории | NO_SELECTION, линия закрыта |
| `altcoin-carry-001` | фандинг-премия (ядро) | NO_SELECTION, премия найдена |
| `altcoin-carry-rm-001` | портфельный дерискинг | NO_SELECTION, оверлеи хлыстуют |
| `altcoin-carry-sl-001` | стопы/тейки, 30 конфигов | NO_SELECTION, чемпион найден |
| **`altcoin-carry-final-001`** | **закалка чемпиона** | **SELECT — живая стратегия** |
| `altcoin-mr-tf-001` | отскоки × 4 ТФ | NO_SELECTION, линия закрыта |

## Файлы внутри протокола (глоссарий)

| Файл | Что это |
|---|---|
| `input-manifest.json` | какие данные/протокол/коммиты использованы (SHA-256) |
| `sweep-progress.json` | полный чекпоинт: метрики каждой конфигурации сетки |
| `development-metrics.csv` | та же таблица плоским CSV |
| `statistics.json` | SPA, Holm, DSR (+ heritage report) по всем конфигам |
| `eligibility-table.json` | кто прошёл базовый отсев и почему |
| `selection-dossier.json` | глубокая проверка кандидатов: bootstrap, стресс |
| `verdict-final.json` | **итоговый вердикт прогона** (начинать смотреть отсюда) |
| `run-metadata.json` | сколько длилось, сиды, версия Python |

Только в `altcoin-carry-final-001/`:

| Файл | Что это |
|---|---|
| `forward/` | **живой дневник** стратегии: `report.md` (смотри его!), `trades.jsonl`, `state.json` |
| `select-daily-returns.{csv,json}` | дневная доходность SELECT-конфига 2021–2026 — для портфельного анализа с внешней D6 |

Папки `research/` и `tests/` на скриншоте выше уровня — это корень репозитория
(код движков и тесты), а не часть артефактов.
